# Third-Party Creative Assets

Only CC0 1.0 Universal creative assets may be Approved.

| ID | Asset | Type | Author | Source URL | Retrieved | License | Filename | SHA-256 | Usage | Evidence | Status |
|---|---|---|---|---|---|---|---|---|---|---|---|

For every external creative asset retain:

- original/authoritative source URL
- author/publisher
- retrieval date
- screenshot of source page
- screenshot/copy of CC0 license evidence
- license text or official license-page copy
- original filename
- SHA-256
- intended use

Missing information means `Pending Evidence`, not Approved.
