# 生成画面の難易度・ランダム表示 — 2026-10-02

## 変更

難易度セレクトを部屋確認ダイアログから生成ボタン直前へ移した。選択肢は「文章に合わせる」「やさしい」「標準」「難しい」。初期値の「文章に合わせる」では、解析された自然文の難易度を使い、未指定なら標準とする。3段階を直接選択した場合は自然文より優先する。自動／手動は同じ解決関数を使い、確認中・生成中・Play中の選択変更を無効化する。確認ダイアログには適用される難易度と被害・回復値を表示する。

部屋確認ダイアログは「ランダム」の指定を表示し、Seedから抽選した部屋の有無・種類・階別カードを先に表示しない。容量都合で外れたランダム種類を列挙する警告も、明示指定を優先する共通説明へ置き換えた。「必ず置く」や固定Start/Goalのカードは残し、数・位置・商品を調整できる。階別の固定／ランダム指定も独立して扱う。同じ種類でも、明示した通常部屋とランダムな端点のカードを混同しない。

表示対象だけを絞り、内部の生成プランはすべて保持する。Seed・確率・上限・明示個数・生成方式・罠判定・経路検査は変更しない。確認のキャンセルでは作者状態を変更せず、同じ指定で自動／手動生成した結果も一致する。旧内容レイヤーの互換レビュー対応はこの変更に含まない。
