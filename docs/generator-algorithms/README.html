3つの生成モード

Frozen

Version 1 — Classic

主経路を先に保証し、少数のalternate routeを追加。固定serpentine gridで配置する安定・再現性重視の方式。

Current Recommended

Version 2 — Recommended

V1のgraph/gameplay semanticsを維持しながら、Seedでcolumns・spacing・回転/反転・Roomサイズを変化。

Expandable

Algorithm Lab

BSP、Delaunay+MST、Rooms+Mazes、Random Walk、Cellular Automata、Gameplay Graph、WFCなどを個別選択。
