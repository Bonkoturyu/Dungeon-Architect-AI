Roomを自然に散布し、Delaunay triangulationで近傍候補を作り、 MSTで接続性を保証してから一部edgeをloopとして戻す生成方式。

1. Room scatter

      A

 B          C

        D

 F             E

SeedからRoom centerを生成する。最低中心間距離を要求し、Room rectangleのoverlapも最終invariantで検査する。

2. Delaunay triangulation

      A
     / \
    B---C
     \ / \
      D---E
     /
    F

近傍Room同士の接続候補を作る。現在は外部runtime libraryを使わないproject-authored Bowyer-Watson実装。

3. Minimum Spanning Tree

候補graph

A---B
|\ /|
| X |
|/ \|
C---D

MST

A---B
    |
    D
    |
    C

全Roomをつなぐ最小treeをKruskal + Union-Findで選ぶ。Room数Nならedge数はN-1。

4. Loop restoration

MST                    With loop
A---B                   A---B
    |                   |   |
    D---E      →        C---D---E
    |
    C

MSTに採用されなかったDelaunay edgeから、SeedとloopRatioに基づいてboundedなsubsetを戻す。

Seed, Room count, loopRatio, geometry, Delaunay, MST, loop selection.

Core does not know

DOM, Three.js, Editor, Play, AI provider, DesignIntent, DungeonSpec.
