leaf数が要求Room数に到達するまで、split可能な大きいleafを優先して二分する。

Room + Link

 left subtree        right subtree
      A                    D
      |                    |
      B ------------------ E

各internal partitionでleft/right subtreeの代表Roomを接続するため、N Roomならtree edgeはN-1になる。
