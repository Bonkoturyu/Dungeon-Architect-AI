Dungeon Architect AI

Generator Core Architecture

生成アルゴリズムを交換可能なライブラリとして扱い、UI・Renderer・Play・AI providerから切り離すためのアーキテクチャ。 ES Moduleとして始めるが、同じ契約でWASM / DLL / .so / dylibへ移行できる境界を採用する。

2. Strategy Core package

現在の独立境界

packages/generator-strategy-core/
├─ src/
│  ├─ index.js
│  └─ strategy-core.js
└─ test/

Strategy contract、request normalization、result envelope、provenance、registryを担当。

依存禁止

DOM / Three.js / Editor state / Play runtime / OpenAI API / Cloudflare / Vite。

Coreの入出力はJSON互換データだけ。

3. 共通Request

{
  "apiVersion": "1.0",
  "seed": 123456789,
  "id": "generated-123456789",
  "prompt": "exploration-heavy dungeon",
  "intent": { "exploration": 0.9, "routeChoice": 0.7 },
  "constraints": { "roomCount": 10, "floorIndex": 0 },
  "options": { "algorithmSpecific": true },
  "context": {}
}

seedは必須。Algorithm固有parameterは options に閉じ込め、共通APIを汚染しない。

4. 共通Result

{
  "spec": { "...": "DungeonSpec" },
  "provenance": {
    "apiVersion": "1.0",
    "strategyId": "version-2-spatial",
    "algorithmVersion": "2",
    "seed": 123456789
  },
  "diagnostics": {
    "profile": {}
  }
}

spec

下流が利用する正式成果物。原則としてvalidなDungeonSpec。

provenance

再現・比較・提出証拠。Strategy ID / Algorithm Version / Seedを保持。

diagnostics

BSP tree、MST edges、retry数など。Application runtimeは依存しない。

7. Coreの責務

Coreで行う

  • algorithm optionsのnormalize
  • deterministic PRNG
  • algorithm-native structure生成
  • algorithm invariant validation
  • plain-data result返却

Coreで行わない

  • HTML / DOM
  • Three.js mesh
  • Editor command
  • fetch / network
  • localStorage
  • cloud provider呼び出し

8. DLL / shared library境界

現在はJavaScript ES Moduleだが、外部言語との境界はJSON messageとして固定する。 Native実装へ移してもrequest/result schemaを維持する。 

const char* dai_generator_metadata_json(void);

int dai_generate_json(
    const char* request_utf8,
    char** result_utf8
);

void dai_free_string(char* ptr);

Windows

generator_bsp.dll

Linux

libgenerator_bsp.so

macOS

libgenerator_bsp.dylib

Browser

WASM + JS Adapter
DLL化しやすい設計とは、Native化そのものより「Pure Core + stable DTO + explicit ownership + explicit Seed」を先に守ること。
