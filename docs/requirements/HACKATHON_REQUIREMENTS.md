# AI Builder Hackathon 2026 — Production Requirements

## Official timing

- Build start: 2026-09-11 16:00 CEST / 23:00 JST
- Build end: 2026-11-11 16:00 CEST / 23:00 JST
- Submission deadline: 2026-11-11 16:30 CEST / 23:30 JST

Internal production start was intentionally delayed to 2026-09-12 00:00 JST.

## Core requirement

The browser experience must transform plain language into interactive 3D scenes and working logic.

## Submission requirements

- Public code repository
- Hosted browser demo
- Demo video under 3 minutes
- Short written description
- Selected focus category
- Any additional requested materials

## Technology

No specific 3D framework is required. Official examples include Three.js, Babylon.js, React Three Fiber, WebGPU, custom pipelines, Unity and Unreal Engine. Backend services may be hosted separately if the browser experience remains accessible and functional.

AI coding assistants, LLM APIs, open-source models, libraries, procedural systems, and AI-generated assets are permitted subject to rights/licensing/compliance requirements.

## Project controls derived from the rules

- Keep public demo functional during judging.
- Expect judges to try prompts not shown in the demo video.
- Keep repository and asset provenance auditable.
- Do not use third-party material with incompatible restrictions.
- Keep API keys and private data out of the public repository.
