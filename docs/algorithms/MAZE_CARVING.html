Algorithm Lab — Maze Carving

Status: DAI-100 implementation candidate.

Strategy ID: algorithm-lab.maze-carving

Architecture

Exact compact lattice from Room count
→ all cardinal candidate walls
→ Seeded randomized Kruskal
→ perfect-maze spanning tree
→ optional restored walls as loops
→ validated DungeonSpec

Algorithm

  1. Build exactly N active cells on a compact integer lattice.
  2. Enumerate every cardinal adjacency as a candidate wall.
  3. Shuffle walls deterministically from the Seed.
  4. Remove a wall when it joins two disjoint components.
  5. Stop after N−1 carved walls.
  6. Find the tree diameter and map its endpoints to first/last Room IDs.
  7. Use remaining walls as deterministic route-choice loop candidates.

Why this is distinct

Rooms + Mazes randomizes the connected footprint before carving. Maze Carving keeps the footprint fixed for a given Room count and randomizes only wall-removal order. That makes topology variation directly attributable to the carving algorithm.

Inputs

  • seed
  • roomCount 3–64
  • extraConnectionRatio 0–1
  • roomSizeMin / roomSizeMax
  • cellSpacing

Invariants

  • exactly N Rooms;
  • exactly N−1 perfect-maze tree edges;
  • connected graph;
  • no self/duplicate edges;
  • all Product Corridors are cardinal lattice edges;
  • Seed-deterministic carving;
  • plain JSON-compatible Core output.

Product adapter

The accepted Generator V1 path supplies DesignIntent-derived content semantics. Maze Carving replaces only spatial Rooms/Corridors. Tree edges become backbone; restored wall edges become alternate.
