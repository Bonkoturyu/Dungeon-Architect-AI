Algorithm Lab — Wave Function Collapse (WFC)

Status: DAI-100 implementation candidate.

Strategy ID: algorithm-lab.wfc

Architecture

Guaranteed Start→Goal backbone
→ local N/E/S/W socket domains
→ minimum-entropy collapse
→ adjacency propagation
→ collapsed Room graph
→ validated DungeonSpec

Why hybrid

WFC is a local constraint solver. Dungeon Architect AI keeps global connectivity as a hard backbone constraint and lets WFC decide compatible local module openings around that backbone.

Tile representation

Each Room cell collapses to a four-bit North/East/South/West socket mask. Masks correspond to local module classes such as dead ends, straights, turns, T-junctions, and crosses.

Collapse process

  1. Build exact-N serpentine Room cells.
  2. Mark mandatory backbone sockets.
  3. Filter each cell domain to legal local masks.
  4. Propagate socket compatibility.
  5. Select the unresolved minimum-entropy cell.
  6. Choose one weighted tile deterministically from the Seed.
  7. Propagate again.
  8. Repeat until all cells are collapsed.

DesignIntent

routeChoice controls the probability of optional sockets while mandatory backbone sockets remain fixed. Zero produces only the guaranteed backbone; one opens every optional active-cell adjacency.

Invariants

  • exactly N Rooms;
  • exactly N−1 mandatory backbone edges;
  • Start→Goal connectivity;
  • socket equality on shared boundaries;
  • no self/duplicate edges;
  • cardinal Product Corridors only;
  • deterministic Seed behavior;
  • plain JSON-compatible Core output.

Diagnostics

  • collapse count;
  • propagation revisions;
  • contradiction count;
  • tile histogram;
  • entropy trace;
  • optional adjacency and cycle metrics.
