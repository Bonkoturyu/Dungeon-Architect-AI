Algorithm Lab — Gameplay Graph / Grammar

Status: DAI-100 implementation candidate.

Strategy ID: algorithm-lab.gameplay-grammar

Architecture

DesignIntent-derived semantic weights
→ MISSION grammar
→ critical spine
→ semantic Room roles
→ dead-end / bypass productions
→ cardinal embedding
→ semantic Entity placement
→ validated DungeonSpec

Semantic roles

  • start / goal
  • challenge
  • hazard
  • reward
  • recovery
  • traversal
  • climax

Grammar productions

  • MISSION→SPINE
  • CHOICE→BYPASS(2)
  • CHOICE→DEAD_END(1)
  • CHOICE→DEAD_END(2)

Topology invariant

Each two-node bypass rejoins the next spine Room and creates exactly one cycle. Thus cycleRank === bypassBranchCount.

Product integration

The adapter keeps accepted V1 content counts and Entity IDs but remaps Entity room placement to grammar roles. Existing entity-referenced Events therefore remain valid while the dungeon gains semantic progression.
