Algorithm Lab — Cellular Automata

Status: DAI-100 implementation candidate.

Strategy ID: algorithm-lab.cellular-automata

Architecture

Seeded cave mask
→ cellular smoothing
→ largest connected component
→ deterministic connectivity repair when needed
→ connected Room subset
→ spanning tree + local loops
→ validated DungeonSpec

Algorithm

  1. Randomize interior wall/floor cells from the Seed.
  2. Apply eight-neighbor cellular smoothing.
  3. Find cardinally connected open components.
  4. Keep the largest component.
  5. Deterministically carve adjacent cells only when the component is too small.
  6. Select exactly the requested number of connected Room cells.
  7. Keep the selection-parent edges as a spanning tree.
  8. Map tree-diameter endpoints to first/last Room IDs.
  9. Add a bounded subset of unused selected-cell adjacencies as loops.

Inputs

  • seed
  • roomCount 3–64
  • extraConnectionRatio 0–1
  • initialWallProbability 0.1–0.9
  • smoothingIterations 0–8
  • wallThreshold 1–8
  • roomSizeMin / roomSizeMax
  • cellSpacing

Invariants

  • exactly N Rooms;
  • exactly N−1 tree edges before loops;
  • connected graph;
  • no self/duplicate edges;
  • cardinal local Product Corridors;
  • deterministic Seed behavior;
  • plain JSON-compatible Core output.

Connectivity repair

Disconnected cave output is handled explicitly. The largest component is retained and adjacent wall cells are carved deterministically only if more connected capacity is required. The repair count is exposed in diagnostics.

Product adapter

The accepted Generator V1 path supplies DesignIntent-derived content semantics. Cellular Automata replaces only Rooms/Corridors. Tree edges become backbone; local adjacency loops become alternate.
